# 📋 Collaborative To-Do List Application

A multi-user task management system built using **Java and JavaScript**, designed to demonstrate differences in programming paradigms, concurrency models, and system design.

---

# 🚀 Project Overview

This project implements the same application in two programming languages:

- ☕ Java (Object-Oriented + Multithreading)
- 🌐 JavaScript (Async/Await + Event-driven model)

It allows multiple users to manage tasks collaboratively with features like task assignment, categorization, status tracking, and data persistence.

---

# 🎯 Features

## 👤 User Management
- Add new users
- View all users
- Assign tasks to users

## 📝 Task Management
- Create tasks
- Delete tasks
- Update task status (Pending/Completed)
- View tasks by user
- View all tasks

## 📂 Task Categories
- Work
- Study
- Personal
- Shopping
- Other

## 💾 Data Storage
- Java → File Serialization (.dat files)
- JavaScript → JSON file storage

## ⚡ Concurrency
- Java → Multithreading using `Thread`
- JavaScript → Async/Await + Promises
