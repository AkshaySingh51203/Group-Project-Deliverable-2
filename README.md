# Collaborative To-Do List Application

## Project Overview

The Collaborative To-Do List Application is a Java console-based application developed to help multiple users organize and manage shared tasks efficiently. The application allows users to create user profiles, assign tasks, update task information, mark tasks as completed, search for tasks, and delete tasks when they are no longer needed. This project demonstrates Java programming concepts such as Object-Oriented Programming (OOP), Java Collections Framework, and exception handling through a simple and user-friendly menu-driven interface.

---

## Features

The application provides the following functionality:

* Add new users
* View registered users
* Create and assign tasks
* View all tasks
* Update task details
* Mark tasks as completed
* Search tasks using keywords
* Delete tasks
* Menu-driven console interface
* Input validation using exception handling

## Run Instructions

Run the application using:

```bash
java Main
```

### If using an online compiler:

1. Open your preferred Java online compiler.
2. Copy and paste the contents of **Main.java** into the editor.
3. Click **Run**.
4. Follow the menu displayed on the console.

---

## Application Workflow

1. Add one or more users.
2. View the registered users.
3. Create and assign tasks to users.
4. View all available tasks.
5. Update task details.
6. Mark tasks as completed.
7. Search tasks using keywords.
8. Delete completed or unnecessary tasks.
9. Exit the application.
